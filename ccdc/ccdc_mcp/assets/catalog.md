# Childhood Cancer Data Catalog: participating resources

The Childhood Cancer Data Catalog (CCDC) is an inventory of pediatric oncology data resources and their dataset summaries. A resource record describes the organization or tool, its data content types, contact information, and links to its dataset summaries. The catalog helps users find data, but it does not grant access to the underlying datasets.

The participating-resources page supports filtering by **Resource Type** and **Data Content Type**. The available values and their counts come from the live `list_filter_options` tool. A resource's linked summaries come from `list_resource_datasets`.

Catalog records are updated periodically. For the latest dataset information or access requirements, consult the resource owner using the link or contact details in its record.
